# Buddh Circuit Formula V Game

## Project layout

- `index.html` — telemetry and SVG track dashboard
- `Buddh Circuit – F1 Cockpit.html` — standalone cockpit driving game
- `assets/css/` — dashboard styles
- `assets/js/` — dashboard and simulator logic
- `assets/svg/` — clean and detailed track exports
- `data/` — track data in JavaScript and JSON formats
- `drafts/` — unfinished experimental code; it is not loaded by either game page

Open either HTML file directly in a browser to run that experience. The dashboard's export buttons load SVG files from `assets/svg/`.
